برنامج معلوماتي لتقييم الفهم الكتابي عند الحبسي الراشد (SAWCA)
إعداد الطالب: شتوان أسامة | إشراف الأستاذة: صام نادية
جامعة لونيسي علي - البليدة 2 (2021 / 2022)
====================================================================

محتويات الحزمة النهائية للمشروع:
1. index.html : التطبيق الكامل (واجهة الاستقبال + التسجيل + محرك الاختبار لـ 58 بنداً + التقرير السريري النهائي + لوحة التحكم).
2. img/       : مجلد الصور المرقمة بالتسلسل من 1 إلى 160.
3. data/      : ملفات قواعد البيانات المدمجة (جدول المعايرة 32 حالة + البنود 58).

طريقة التشغيل:
- افتح ملف index.html بأي متصفح حديث على الحاسوب أو التابلت أو الهاتف (في الوضع الأفقي Landscape).
- للدخول إلى لوحة التحكم الاحتياطية للأخصائي: اضغط على زر (لوحة التحكم) أو اختصار (Ctrl+Shift+A) وأدخل الرمز: 2022.
- لإيقاف الاختبار مؤقتاً أثناء التقييم: اضغط زر (Esc) أو انقر 3 نقرات متتالية في الزاوية العليا اليسرى للشاشة.
